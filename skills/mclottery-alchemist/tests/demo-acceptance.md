# 动态工作台 Demo 验收清单

以下是人工验收清单。独立 HTML 的通过仅代表页面交互工作，不代表 MCP 已连接或真实工具调用已经成功。

## 页面和交互

- [ ] 打开 Demo 后默认显示总览，并有清晰的“示例数据”状态。
- [ ] 左侧导航可以切换：总览、积分体检、积分兑换、抽奖活动、中奖记录、我的卡包、MCti 人格、今日欧气。
- [ ] 汉堡/薯条角色、星光、卡片、麦签和弹窗动画工作；系统减少动态效果时动画降级。
- [ ] 积分体检可修改固定消耗试算次数，结果标注为“预计值”，不执行抽奖。
- [ ] 兑换列表搜索、筛选、商品详情可以操作；`point=0` 且有现金费用、售罄、下架、预热、未开始或已截止项不作为可兑换候选。
- [ ] “抽奖前检查”只将意图交给 Agent；“模拟仪式”需要勾选演示声明，生成的结果明确标为非真实中奖。
- [ ] 中奖记录显示状态与提醒；提醒缺失时不编造核销期限。
- [ ] 卡包页提醒：券存在不代表在当前门店/订单可用。
- [ ] MCti 展示八种人格，并支持逐题、快速测试、跳题、多选、自选人格、分享、改答、重测及朋友搭子建议。
- [ ] 已生成名片后修改某一题，页面能重新进入该题并保留此前答案，不丢失正在编辑的答案。
- [ ] 所有动画不影响事实状态；减少动态效果偏好可正常生效。
- [ ] 今日麦签星级、宜/忌与幸运单品均明确属于纯娱乐。
- [ ] 右侧对话快捷入口在独立模式下仅使用本地演示路由；内嵌宿主模式应发送意图事件。

## 真实数据集成

- [ ] 用户在 Agent 宿主而非网页中配置 `mcd-mcp`。
- [ ] 宿主只读查询结果通过 `mclottery:state` 推送页面。
- [ ] `mode=live` 时缺失的账户、活动、商品、中奖记录或卡包数据不会残留示例内容。
- [ ] 页面动作仅发意图给 Agent；宿主根据 Skill 决定使用哪些 MCP 工具。
- [ ] `lottery_preflight` 不执行抽奖；实际 `draw-lottery` 只能在成本披露、明确授权和守卫允许后执行。
- [ ] 真实抽奖调用一次只抽一次；结果未知时不重试，并按 Skill 规则对账。
- [ ] 没有任何账户 Token 或凭据进入网页、URL、LocalStorage 或消息 payload。
