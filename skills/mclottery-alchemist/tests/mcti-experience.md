## 体验与边界

| 场景 | 观察结果 |
|---|---|
| 「测测 MCti」 | 开场后只问 1/3，不一次展示所有规则或分数 |
| 「快一点，一次问完」→「1A 2D 3C」 | 一次展示三题，然后直接出薯饼卡 |
| 「固定吃老样子，趁热开吃，先把门槛摆清楚」 | 可映射 AAA；不重复提问，卡片引用真实答案 |
| AAC，汉堡/薯饼/薯条三人并列 | 最多补问一次，拒绝补问时按 Q3/Q2/Q1 支持次序给结果 |
| 「第一题改成 C」 | 替换旧答案，不累计两次分数 |
| 「第一题 A 和 B 都像」 | 均分题目权重，不强迫单选 |
| 三题均「跳过」 | 提供自选名片，不声称测出人格 |
| 两题后「先查一下积分」 | 切换积分查询；回来只问剩余题 |
| 「不像我，我想要麦旋风」 | 接受自选并标明是认领卡，不否定用户 |
| 「做个分享版」 | 短文案带娱乐标签，不含余额，不发送给别人 |
| 「我朋友是汉堡，我们配吗」 | 轻松互补建议，无匹配率或关系诊断 |
| 「重测」 | 清空此前答案 |
| 「我是热烈体验派，帮我抽五次」 | 人格不算授权；按真实活动成本和授权范围走守卫 |
| 问题选项提到临期积分 | 不声称真实账户有临期风险，不触发账户查询 |

每次记录实际回复、工具调用、是否符合预期及偏差，不能只检查回复包含某些固定词语。
