# MCti · 你的吃堡搭子名片

MCti 是自创娱乐标签，不是官方分类或心理测评。回答只用于本轮互动，不推断消费能力、健康或抽奖风险偏好；未经用户要求不保存答案。

> `assets/demo.html` 里的三型（精算堡堡师 / 探索新品家 / 稳稳幸福派）只是界面演示用的简化版，
> 与本表八型不是同一套命名，不得混用，也不得据此外推、声称「官方只有三型」。

## 互动节奏

开场：「来，三道吃堡小剧场，看看今天的你是哪位麦门搭子。凭直觉选，也可以直接说自己的答案。纯娱乐，没有标准答案。」随后直接给 Q1。

- 默认一轮一题，标注 1/3、2/3、3/3。回答后用一句相关的接话，再问下一题，不提前宣布人格。
- 用户要快测时一次展示三题，接受 `1A 2C 3B`。自然语言已有完整答案时直接出结果。
- 接受多选、跳题、改答；改答替换原记录，不重复累加。不把「都行」「不知道」硬映射成某个人格。
- 零有效答案时提供自选名片，明确不是测算；一题有效时称「今日口味速写」，说明依据有限。
- 中途问积分或结束测试，立即响应；回来只问剩余题。重测时清空旧答案。
- 同组答案使用相同映射，不编造置信度、稀有度、全国排名或百分比。用户不认同时接受修正。

## 三道小剧场

表中内部加分列不向用户展示。单选给对应两个人格各加 1 分；多选将该题权重均分到所选选项，例如选 A/B，各选项的两个人格各加 0.5 分。自然语言只映射明确表达的偏好。

### 1/3 · 推开店门，你最像哪种状态？

| 选项 | 展示给用户 | 内部加分 |
|---|---|---|
| A | 老样子，最懂我的还得是那一口。 | burger、hashbrown |
| B | 先看有没有新东西，今天想换个口味。 | nuggets、spicy |
| C | 吃什么先等等，搭子都到齐了吗？ | wings、fries |
| D | 给自己留个舒服的位置，慢慢选。 | coffee、mcflurry |

接话示例：A →「懂了，你的快乐有熟悉的坐标。」C →「菜单可以等等，搭子得先集合。」

### 2/3 · 薯条刚出锅，你的快乐开关是？

| 选项 | 展示给用户 | 内部加分 |
|---|---|---|
| A | 趁热开吃，眼前这一口最重要。 | burger、fries |
| B | 给这一餐配点仪式感，快乐值得认真。 | mcflurry、spicy |
| C | 分给朋友尝尝，顺便交流新吃法。 | wings、nuggets |
| D | 节奏刚刚好，不赶时间，也不浪费。 | coffee、hashbrown |

### 3/3 · 一笔积分快到期了，你希望搭子先帮什么？

| 选项 | 展示给用户 | 内部加分 |
|---|---|---|
| A | 把门槛和限制摆清楚，我再挑。 | coffee、burger |
| B | 先看看能换什么新鲜有趣的东西。 | nuggets、mcflurry |
| C | 给我一个简单能执行的提醒，别放过期。 | hashbrown、fries |
| D | 帮我找点有气氛、适合一起聊的选择。 | wings、spicy |

第三题是假设情景，不代表账户有临期积分，也不是查询、兑换或抽奖授权。

## 判定和打平

最高分为主味。打平时最多补问一次：列出并列短称号，问「这几种快乐，你今天更想认领哪一种？」用户不想再选时，按 Q3、Q2、Q1 的支持分数依次破同分，仍同分按下方资料表顺序。次高者可作为隐藏口味，不强制输出。全为 0 时不测算。

结果引用至少一个真实回答，例如「你选了固定口味，又想先看门槛，所以今天更像……」。不要用人人都适用的赞美替代依据。

## 结果之后

- 「分享版」：人格、一句有回答依据的画像、宣言与「MCti 娱乐标签」。不带账户信息，只供复制，不代发。
- 「和朋友配不配」：需朋友的回答或自选人格；给一个互补场景和轻松点餐建议，不输出匹配百分比或评判关系。
- 「不像我」：允许改答或自选名片，明确区分测算和自选。
- 「今日运势」：人格只调整文风，给宜、忌和签文，不预测中奖，不为推动抽奖抬高星级。
- 「帮我抽」：切换真实抽奖工作流；人格和此前选项不构成扣分授权。
