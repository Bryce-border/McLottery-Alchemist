# MCti 八种吃堡人格

> MCti 是本 Skill 自创的娱乐标签体系，不是麦当劳官方分类，也不是心理学量表。
> 结果只用于语气和积分策略建议，**不代表真实消费偏好，也不影响任何中奖概率**。

## 数据结构

```json
{
  "id": "fries",
  "name": "薯条人格",
  "title": "快乐速享派",
  "keywords": ["即时满足", "行动派", "分享欲"],
  "lucky_item": "薯条",
  "points_strategy": "优先关注即将过期积分与可兑换商品",
  "success_line": "积分可以攒，薯条必须趁热。",
  "failure_line": "这次欧气暂时离线，先稳住积分小金库。",
  "risk_preference": "moderate"
}
```

`risk_preference` 只用于措辞轻重，**不得**据此建议用户增加抽奖次数。

## 八种人格

### 1. `burger` 汉堡人格 · 饱腹实干家

- 关键词：务实、满足感、实际价值
- 幸运单品：巨无霸（娱乐推荐，不代表在售或可兑换）
- 积分倾向：看重明确用途与兑换价值
- 建议：先看真能换什么，再考虑娱乐抽奖
- 宣言：「不求一夜暴富，只求每一口都值。」

### 2. `fries` 薯条人格 · 快乐速享派

- 关键词：即时满足、行动派、分享欲
- 幸运单品：薯条 / 薯格
- 积分倾向：不喜欢积分闲置
- 建议：先查临期积分与可兑换项，别让积分躺着过期
- 宣言：「积分可以攒，薯条必须趁热。」

### 3. `nuggets` 麦乐鸡人格 · 探索盲盒家

- 关键词：好奇、尝鲜、随机惊喜
- 幸运单品：麦乐鸡
- 积分倾向：对新活动和随机奖品有兴趣
- 建议：先弄清成本与规则，再按预算参与
- 宣言：「人生可以没有答案，但抽奖必须有期待。」

### 4. `spicy` 麦辣人格 · 欧气冒险家

- 关键词：刺激、挑战、冒险精神
- 幸运单品：麦辣鸡腿堡
- 积分倾向：能接受娱乐性损失
- 建议：先设预算和停止条件，不因未中奖而追加
- 宣言：「可以辣到流泪，但不能抽到破产。」

### 5. `mcflurry` 麦旋风人格 · 浪漫许愿家

- 关键词：仪式感、情绪价值、浪漫
- 幸运单品：麦旋风
- 积分倾向：重视自己喜欢的奖品和体验
- 建议：优先换真正想要的东西，别为情绪追加投入
- 宣言：「生活已经够苦，今天必须甜一下。」

### 6. `hashbrown` 薯饼人格 · 稳健囤分派

- 关键词：规划、耐心、风险控制
- 幸运单品：薯饼
- 积分倾向：重视兑换确定性与有效期
- 建议：先看到期风险，再安排使用顺序
- 宣言：「我的积分不是没花，只是在等最佳买点。」

### 7. `wings` 麦辣翅人格 · 社交气氛组

- 关键词：热情、分享、群体快乐
- 幸运单品：香辣鸡翅
- 积分倾向：关注分享与多人场景
- 建议：挑真正适合场景的商品；抽奖仍需控制预算
- 宣言：「一个人中奖叫欧皇，一群人吃堡叫麦门。」

### 8. `coffee` 麦咖啡人格 · 冷静分析师

- 关键词：理性、效率、数据控
- 幸运单品：麦咖啡
- 积分倾向：重视成本、规则与可核实数据
- 建议：比较门槛与可核实价值，优先确定性
- 宣言：「欧气可以随缘，账本必须科学。」

## 判定

三道默认题（用户已提供足够信息就不重复问）：

- Q1 进店状态：A 提前规划直奔目标 / B 到店再看临场发挥
- Q2 积分倾向：A 换确定想要的东西 / B 抽奖体验惊喜
- Q3 临期反应：A 先算兑换方案 / B 先看奖池再决定

映射为四个维度：计划 ↔ 随缘、稳健 ↔ 冒险、实用 ↔ 体验、分享 ↔ 独立（信息不足时不使用分享维度）。

| 回答特征 | 优先人格 |
|---|---|
| 计划 + 实用 + 稳健 | 薯饼 / 汉堡 / 麦咖啡 |
| 即时满足、不想等 | 薯条 |
| 浪漫、仪式感、情绪体验 | 麦旋风 |
| 好奇随机结果 | 麦乐鸡 |
| 明确喜欢刺激挑战 | 麦辣 |
| 喜欢分享、多人场景 | 麦辣翅 |

这是启发式映射，不要求八种均匀分布；信息不足时可以问「哪种描述最像你」。

## 输出格式

1. 人格名（`XX 人格 · 称号`）
2. 2–3 个关键词
3. 一句吃堡画像
4. 今日幸运单品（标注娱乐性质）
5. 积分策略（一句话，可执行）
6. 专属宣言

## 边界

- 不得由人格推断健康、消费能力、性格缺陷等敏感结论。
- 不得说「你这个人格适合多抽几次」。
- 人格结果与抽奖结果无关，抽奖后不得用「人格不合」解释未中奖。
